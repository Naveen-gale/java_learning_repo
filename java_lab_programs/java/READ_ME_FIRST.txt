JAVA LAB PROGRAMS

This folder contains all 20 requested Java lab examples. Program 8 (package) uses two Java files inside package_demo. Java source files contain no comments. JavaApplets.html is the only HTML file.

IMPORTANT:
Java applets were removed from modern Java. The applet programs require an older JDK such as JDK 8 and a compatible applet viewer/browser environment. Modern browsers such as Chrome and Edge do not run Java applets. The HTML file is provided for a compatible legacy environment.

Compile and run an ordinary program from this folder:
    javac FibonacciCommandLine.java
    java FibonacciCommandLine

Fibonacci command-line example:
    javac FibonacciCommandLine.java
    java FibonacciCommandLine 8

Package example:
    Open Command Prompt inside package_demo
    javac college/tools/Greeting.java PackageAccessDemo.java
    java PackageAccessDemo
